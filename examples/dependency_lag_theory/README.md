# Registry-Dated Dependency-Lag Theory

This directory freezes the design contract for `THY-003`. It does not contain
an executable study, Selection memberships, Agent outcomes, or a paid campaign.

`plan.json` defines one outcome-free falsification study and the downstream
Agent-outcome decision contract. Its canonical digest (with `plan_digest`
omitted) is `0126c44a…3d5d`. The current authorized next action is to
implement only the outcome-free study as a direct example-layer runner. Agent
outcome replay remains prohibited until every source, forecast, materialization,
null, and reproduction gate in the plan passes and a separate outcome plan is
frozen.

`source-feasibility.json` records bounded design evidence from the ignored
SWE-rebench and repository caches. Its npm registry sample is exploratory:
publication times were filtered by historical Origin cutoffs, but the raw
packument responses were not retained and the registry can mutate. The frozen
study must cache and digest every raw response before using it as
counterfactual evidence.
