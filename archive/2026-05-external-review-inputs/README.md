# 2026-05 External Review Inputs

This archive keeps selected external-review prompts and problem briefs from the
proposal-stage research process.

It intentionally does not keep the full review bundles. The omitted bundle
contents mostly duplicate active reports, configs, candidate inventories, or
process runbooks, and some paths include raw or intermediate artifacts that
should not be active mainline material.

Use these files as examples for future external review packets and as historical
context for why the project moved away from the old weighted selector and
treats task generation as supply infrastructure.

The active synthesis of these inputs is
`docs/research/research-inputs-and-related-work-reference.md`.

## Files

- `weighted-pilot-direction-review-readme.md`: prompt context for reviewing the
  failed weighted pilot and selecting the next algorithmic direction.
- `task-generator-problem-brief.md`: problem brief for task generator/source
  adapter weakness and related-work positioning.
- `candidate-policy-validation-gpt55-prompt.md`: prompt for adversarial review
  of the frozen candidate policy and validation protocol.
- `candidate-policy-adversarial-review-readme.md`: compact review packet README
  for the same candidate-policy review.

## Boundary

These files are historical references. Current project state is defined by
`docs/research/project-state-after-proposal.md`.
